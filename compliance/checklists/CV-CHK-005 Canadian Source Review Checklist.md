## 1. Purpose

This checklist defines the review steps used to approve Canadian official, open-
government, public registry, PDF, CSV, API, or website sources before they are used
in Civic Voice Canada public launch pages.

Its goals are to:

- Confirm that every source used in the app meets the source eligibility criteria in
  CV-POL-002 before any data from that source is displayed publicly.
- Document the licence or terms-of-use status for each source in a consistent and
  auditable way, and assign a Licence Status that can be recorded in CV-REG-001.
- Identify personal information risks, public official data risks, transformation
  requirements, and attribution obligations before a source goes live.
- Produce a signed evidence record for each approved source that supports CV-REG-001,
  CV-SOP-001, and the data source pre-launch gate in CV-CHK-002.
- Prevent unapproved, unofficial, or legally unclear sources from reaching the
  public-facing app.

---

## 2. Scope

This checklist applies to:

- All data sources intended for use in the Canadian public launch of Civic Voice Canada
- New sources added after public launch
- Re-reviews of existing sources when a licence change, terms-of-use change, or
  source structure change is identified
- Sources in any format: official open-data portal, government API, official PDF,
  official CSV/XLSX, statutory commissioner's register, public registry, or
  official website data

This checklist does **not** apply to:

- Internal Civic Voice Canada data (e.g., aggregated citizen-opinion vote counts)
  that is generated by the app itself and not sourced from a third party
- Data that is not displayed to users (e.g., internal configuration)

---

## 3. Source Review Principle

**Every source used in a Civic Voice Canada public page must be reviewed and approved
using this checklist before its data is written to Firestore or displayed to users.**

A source that has not completed this checklist with a Final Decision of Approved for
Public Display, Approved with Limitations, or Public Registry — Use with Attribution
must not be used in the public-facing app. A Deferred or Blocked decision means the
source must not be used until the review is completed and a positive decision is
recorded.

The source review is separate from data verification. A source may be approved by
this checklist and still require a completed CV-REC-001 Data Verification Checklist
before the specific dataset is written to Firestore.

## 6. Licence / Terms Review

| Item ID | Review Area | Requirement | Pass / Fail / NA | Evidence | Reviewer | Date | Notes |
|---|---|---|---|---|---|---|---|
| LIC-01 | Licence or terms identified | A licence or terms-of-use document governing reuse of the source data has been identified and its URL or title recorded | | | | | |
| LIC-02 | Licence permits reuse | The identified licence or terms explicitly permit reuse, reproduction, or publication of the data for the purpose of civic information display (commercial or non-commercial, as applicable) | | | | | |
| LIC-03 | Attribution required | Whether the licence or terms require attribution has been determined. If attribution is required, the required attribution wording or format is recorded in Section 7 of this checklist and in CV-REG-001. | | | | | |
| LIC-04 | No prohibited uses | The licence or terms do not contain a prohibition that would prevent Civic Voice Canada's intended use of the data (e.g., no prohibition on aggregation, no prohibition on digital publication, no prohibition on transformations of the type applied) | | | | | |
| LIC-05 | Licence Status assigned | A Licence Status has been assigned for CV-REG-001 from the approved set: **Approved** / **Public Registry** / **Manual Review Only** / **Review Required** / **Not Approved** | | | | | See definitions below |
| LIC-06 | Licence version noted | The version or effective date of the licence or terms relied upon is recorded | | | | | Important where licences have multiple versions (e.g., OGL-Canada v1 vs v2) |
| LIC-07 | Terms change monitoring | A process or note exists to identify if this source's licence or terms change in the future (e.g., periodic re-review scheduled, source monitor noted in CV-SOP-002) | | | | | |

**Licence Status definitions:**

| Status | Definition |
|---|---|
| **Approved** | Licence explicitly permits reuse with attribution. Attribution wording confirmed. No legal review required before use. |
| **Public Registry** | Data is from a statutory public register or official public registry where no licence is required for reporting on public official information. Attribution and source note required. |
| **Manual Review Only** | Data may be used only as a reference for manual review and must not be displayed directly in the public UI without transformation, verification, and a Manual Review flag. |
| **Review Required** | Licence or terms are unclear, ambiguous, or not yet identified. Source must not be used in the public-facing app until status is resolved. |
| **Not Approved** | Licence or terms prohibit the intended use, or the source is not from an eligible source type. Source must not be used. |

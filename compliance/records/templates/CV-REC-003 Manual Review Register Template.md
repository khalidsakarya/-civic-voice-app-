## 1. Register Purpose

This register tracks all data items that have been flagged for manual review — either
because they failed verification checks, because their source is temporarily
unavailable, because the data is pending licence clearance, or because a correction
request has implicated the item.

A flag in this register corresponds to a status label of **"Manual review required"**
or equivalent being displayed in the public UI for the affected data item.
